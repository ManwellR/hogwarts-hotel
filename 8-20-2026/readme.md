# Hogwarts Hotel

A responsive landing page for a fictional Hogwarts hotel.

## About
I built this project to practice creating a complete website from scratch using HTML, CSS, and Bootstrap. My main focus was improving my ability to structure webpages into sections, create responsive layouts, work with Bootstrap components, and customize the design with my own CSS.

## Built With

- HTML5
- CSS3
- Bootstrap
- Google Fonts

## Features

- Responsive navigation

- Responsive page layout

- Hotel room images and descriptions

- Custom styling alongside Bootstrap

- Footer with navigation and information

## What I'd Improve

- If I rebuilt this project, I would focus more on spacing and content placement. Some sections feel more crowded than others, while other areas have empty space that doesn't feel intentional.

- I would also spend more time planning the layout before styling so that the spacing, text, and images feel more consistent across the entire page.
